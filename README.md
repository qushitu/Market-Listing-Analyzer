Market Listing Analyzer is designed as a private internal reference tool for our team’s market research work and product planning process.

Through the Etsy Open API, the tool collects only publicly visible listing details, such as product names, prices, tags, materials, listing photos, and basic shop information. We use this data to observe marketplace trends, evaluate product categories, and support internal development decisions.

The application is strictly read-only. It has no ability to add, edit, upload, or delete Etsy listings, and it does not request or process private seller data, customer information, orders, payments, or messages.

This tool is used only by our internal team. It is not provided to outside users, is not operated as a public service, and is not monetized in any way.
